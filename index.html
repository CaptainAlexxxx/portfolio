How it works engineering detail

Job time, 10x

Three causes: dispatchAfterResponse silently lost jobs under PHP-FPM, so I replaced it with real queued jobs; a Bus::chain carried 192+ serialized job objects, so it now passes shipment IDs; and a cache lock deadlocked, which I fixed. Claude Code first suggested a fix that looked right and was not; I traced the real causes myself.

Non-idempotent customs API

A retried job would create a duplicate at customs. Redis locks per manifest and per shipment, with TTLs tuned to the API timeout and non-blocking acquisition. Per-job retry policies: one try for non-idempotent calls, retries for the rest. lockForUpdate inside a transaction, so parallel workers never hand out one track number twice.

Register pipeline

An Excel register flows through customs, ERP and WMS on Bus::chain and Bus::batch, modelled as a state machine with rollback and a safe restart after a partial failure.

KPI dashboard, 15 s to 1 s

N+1 queries replaced with GROUP BY aggregates, batches of 500 to stay under the MySQL placeholder limit, and details lazy-loaded on demand.

Integrations

Saloon connectors, retries on 5xx only, typed exceptions. Customs over SOAP with encryption and qualified e-signatures, Cashalot fiscal service, Odoo ERP, OMS/WMS. A feature flag between two customs modes gives an instant rollback. Files on AWS S3.

PDF migration and security

The two PDF helpers moved into one service in 15 steps, covered by PHPUnit feature tests. Security pass: fail-closed webhooks, hash_equals, an IP allowlist that ignores X-Forwarded-For, 2FA attempt limits, hashed reset tokens.

How it works engineering detail

Browser e-signing

Signing runs in a Web Worker through IIT EndUser. The server prepares deterministic XML bytes, the browser signs them, the server sends them unchanged, so the signature never breaks. A SHA-256 content key makes sending idempotent, retries never re-sign, and a scheduled, rate-limited queue sends in batches.

Encrypted customs transport

SOAP with an AES-256-CBC payload, an RSA-encrypted session key and qualified e-signatures. The register chain runs as a queue pipeline: send, poll with backoff, parse, feed the result into the next stage.

Entity resolution

Load-test rows found and excluded first. Match keys handle names in any word order, shared consolidator phones and addresses in mixed languages. A false merge is never acceptable, so anything borderline is queued for a person.

Tenancy and access

Each tenant gets its own users, shipment flow and branding: colours, text or SVG logo, live preview applied across the whole interface. RBAC with 6 roles and about 30 scoped permissions.
